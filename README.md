# 말랑말랑 — 온라인 말랑이

설치 없이 브라우저에서 바로 꾹꾹 눌러 갖고 노는 말랑이(스퀴시) 놀이터.

## 놀이 방법

- **누르기** — 마우스나 손가락으로 꾹 누르면 눌린 깊이에 따라 표정이 평온 → 놀람 → 찡긋으로 바뀝니다.
- **문지르기** — 자국이 손가락을 한 박자 늦게 따라오고, 젖은 마찰음이 납니다.
- **두 손가락** — 벌리면 쭉 늘어나고, 돌리면 몸통이 통째로 비틀립니다. 많이 돌리면 어질어질해해요.
- **맛 고르기** — 다섯 가지 말랑이는 색뿐 아니라 재질이 다릅니다.

## 다섯 가지 재질

| 말랑이 | 성격 | 같은 힘으로 눌렀을 때 함몰 |
|---|---|---|
| 딸기우유 | 딱 알맞게 말랑 | 7.9% |
| 멜론소다 | 탱탱— 오래 통통 튐 | 9.0% |
| 하늘소다 | 물처럼 찰랑찰랑 | 10.3% |
| 포도젤리 | 제일 쫀득, 쭉 늘어남 | 5.3% |
| 레몬푸딩 | 푸딩처럼 푹 | 9.7% |

## 만듦새

의존성 없는 단일 HTML 파일입니다. 외부 라이브러리도, 이미지도, 사운드 파일도 쓰지 않습니다.

- **물리** — 32개 점의 소프트바디. 손가락이 목표 형태를 만들고 표면이 스프링으로 따라갑니다. 깊이 누를수록 덜 들어가는 포화 곡선으로 쫀득함을 내고, 파인 부피는 나머지 둘레로 밀려나 반대쪽이 볼록해집니다.
- **소리** — Web Audio로 전부 합성. 피치가 위로 휘어 오르는 짧은 사인파에 물속 울림을 더해 물방울 소리를 만들고, 맛마다 음높이가 다릅니다.
- **접근성** — 라이트/다크 테마, 키보드 포커스, `prefers-reduced-motion` 대응.

## 로컬에서 보기

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.
